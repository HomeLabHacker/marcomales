## Ausgangssituation

Zu Beginn befinden sich die relevanten Systeme in einer gemeinsamen
bzw. nicht ausreichend voneinander getrennten Netzwerkstruktur.

Beispiel:

                    IST-ZUSTAND

                    gemeinsames LAN
                         |
             +-----------+-----------+
             |           |           |
           CL01        DC01        ADM01
          Client       Server       Admin


Zwischen den Systemrollen besteht keine ausreichende netzwerkseitige
Sicherheitstrennung.

CL01 Windows 11 
ADM01 Windows11
DC01 Server mit AD DS und DNS
